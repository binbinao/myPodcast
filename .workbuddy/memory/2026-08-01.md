## 档 A 落地：缓解单人播客语调单调
- 斌哥反馈单人播客语调太单调，先执行档 A（零成本，不换 TTS）。
- **根因**：旧 tts.py 整段用同一全局 rate/pitch，无句间起伏。
- **关键踩坑（已记入 MEMORY 硬约束）**：edge-tts `Communicate(text=...)` 传完整 `<speak>` SSML 会被错误合成成超长音频（单句 5 字变 36s，含 break 的整段 18 字变 48s）。**绝不能传 SSML**。
- **解法**：新增 `src/prosody.py` 韵律规划器（heuristic 默认零依赖：问句升调/感叹加重/省略放慢/分号紧凑/连续句号句叠正弦波形；可选 llm 模式打情绪标签）+ `tts.py` 改为**逐句 `Communicate(text=单句, rate=句rate, pitch=句pitch)`，ffmpeg 拼 + 句间/段间静音**。必须清洗 emoji/零宽字符。
- config.yaml 加 `prosody: {enable, mode(heuristic|llm)}`。
- 验证：ep-01 重生成 4分58秒/1166KB（时长与原单调版 4分59秒一致，说明无异常时长），韵律已注入；三集已统一重生成。
