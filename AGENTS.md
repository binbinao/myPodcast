## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) plus the five wayfinder labels. See `docs/agents/triage-labels.md`.

### Domain docs

multi-context — a root `GLOSSARY-MAP.md` points at one `GLOSSARY.md` per context. See `docs/agents/domain.md`.
