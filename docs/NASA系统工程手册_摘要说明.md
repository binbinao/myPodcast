# 任务概览：NASA 系统工程手册 深度阅读摘要

## 做了什么
将《NASA 系统工程手册》（NASA/SP-2016-6105 Rev 2，中文译本，737 页）全书通览后，按章节拆解为一份**深度重构型阅读摘要**（约原书 1/4–1/3 篇幅，约 7.9 万字 / 4 万中文字）。

## 关键决策与处理
- **提取**：用 `pypdf` 将全文提取为文本，按章节标题切分为 7 章 + 17 附录的独立文件。
- **质量问题修复**：原书末尾"参考文献"区也以"第 2 章"开头，导致初次切分把第 2 章正文覆盖成参考文献——已定位到 FULL.txt 真实正文行段（320–878 行）重新切片，并重做第 2 章摘要，确保未使用虚构内容。第 2.4 节因原书为图片页正文未提取，已如实标注。
- **摘要生成**：7 章 + 附录群分别由并行子代理通读原文本后产出，严格溯源（标注章/节号）、三段式（论点→论据→案例）、嵌入逐字金句、附术语表。第 6 章因篇幅最长首次超代理步数上限，已重跑完成。
- **组装**：统一标题层级、补全书概览/导航/阅读建议/关键概念速查表，汇成单份 Markdown。

## 交付物

- 中间产物：`raw/_extracted/` 下各章提取文本与摘要草稿（保留备查，原 PDF 未改动）
